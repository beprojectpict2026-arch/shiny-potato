# Datasets

The CSV files are not stored in git. Download them from Kaggle and put them in this folder.

| Used by | Kaggle dataset | Save as |
|---|---|---|
| `a1.py` | Pima Indians Diabetes Database | `data/diabetes.csv` |
| `a4.py`, `a5.py`, `a6.py` | Twitter US Airline Sentiment | `data/Tweets.csv` |

`a2.py` uses the digits dataset built into scikit-learn and `a3.py` needs no data.

Using another dataset: change `CSV_PATH` and the column names (`TARGET`, `TEXT_COL`, `LABEL_COL`) at the top of the script.
