<h2 align="center">1\. Problem Statement</h2>

Build a machine learning model that predicts the type of people who survived the Titanic shipwreck using passenger data (name, age, gender, socio-economic class and so on).

<h2 align="center">2\. Objectives</h2>

1. Read and explore the Titanic passenger data and find which groups survived more often.
2. Clean the data: handle missing values and remove columns that do not help.
3. Create useful features from the existing columns (title, family size) and encode the categorical ones.
4. Train two classification models, Logistic Regression and Random Forest.
5. Compare the models with accuracy and the confusion matrix, and find the features that matter most.

<h2 align="center">3\. Methodology</h2>

**Dataset.** Kaggle "Titanic - Machine Learning from Disaster" (`train.csv`, 891 passengers, 12 columns). The target is `Survived` (1 = survived, 0 = did not). The notebook can use the real file by setting `CSV_PATH`; if the file is not there it generates synthetic data with the same columns, so it runs anywhere.

**Steps**

| Step | What is done | Why |
|---|---|---|
| 1. Explore | Survival rate by sex and by passenger class; count of missing values | Shows which features are related to survival |
| 2. Clean | Fill missing `Age` with the median and `Embarked` with the most common port; drop `Cabin` (most values missing), `Ticket` and `PassengerId` | Models cannot use empty cells, and these columns add little |
| 3. Features | `Title` (Mr, Mrs, Miss, Master, Other) taken from `Name`; `FamilySize = SibSp + Parch + 1`; one-hot encoding of `Sex`, `Embarked` and `Title` | A title carries age and sex information; family size can matter for rescue |
| 4. Split | 75% training, 25% test, with the same share of survivors in both parts (stratified) | The test set is not used for training, so the accuracy is honest |
| 5. Train | Logistic Regression and Random Forest | A simple linear model and a stronger tree-based model to compare |
| 6. Evaluate | Accuracy and confusion matrix on the test set; Random Forest feature importance | Shows how many predictions are right and which features drive them |

**Models.** *Logistic Regression* gives the probability of survival as a weighted sum of the features passed through a sigmoid function. *Random Forest* (200 trees, maximum depth 5, at least 5 samples per leaf) averages many decision trees, each trained on a random part of the data. The depth and leaf limits keep the trees from memorising the training data.

**Measures.** Accuracy = correct predictions / all predictions. The confusion matrix [[TN, FP], [FN, TP]] shows how many people were predicted correctly and which kind of mistake was made: false positives (predicted to survive, did not) and false negatives (predicted not to survive, did).

**5.4 Analysis**

- Women survived far more often than men, and first-class passengers more often than third-class passengers, which matches the "women and children first" rule and better access to lifeboats.
- Both models reach the same accuracy of 0.803. Logistic Regression makes fewer false positives (15 against 20), while Random Forest finds more of the passengers who really survived (55 against 50 true positives).
- The most important features are the title and sex of the passenger, then fare, age and class. These are all linked to being a woman, a child or a rich passenger.

**Limits.** The test set has only 223 passengers, so a difference of one or two percent between models is not meaningful. The model predicts from the available columns and does not show causes.

**Conclusion.** Cleaning the data and adding the title and family size gave a model that predicts survival with about 80% accuracy. Sex, title, fare, age and class were the strongest predictors.
